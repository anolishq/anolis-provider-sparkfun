# anolis-provider-sparkfun

An Anolis device provider for SparkFun Qwiic hardware, built on SparkFun's
Qwiic Python drivers and the Python provider SDK.

- [Hardware](hardware.md): wiring, host preparation, and measuring start-up
  time on the target.
- [Adding a board](adding-a-board.md): what a new board takes, and how to test
  it without the hardware.
- [Coverage](coverage.md): which SparkFun boards and drivers the provider
  supports or could, grouped by chip, with what each needs.
